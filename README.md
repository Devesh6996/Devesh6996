## 🔬 Featured Projects

---

### 🔹 Optimized Adaptive Filtering & Deep Learning for Parkinson's Speech Denoising

#### *Self-Supervised Speech Analysis for Neurological Disorder Detection*

A complete speech analysis framework targeting Parkinson's Disease patients using self-supervised representation learning and adaptive signal processing.

#### Highlights
- Extracted contextual embeddings using frozen **wav2vec 2.0** to reduce data dependence
- Tackled severe class imbalance with **Focal Loss** and threshold optimization
- Improved generalization through **gradient stabilization** techniques
- Achieved **majority voting ensemble** for classification robustness
- Outperformed traditional ML baselines on Parkinson's speech datasets

#### Stack
`Python` • `PyTorch` • `wav2vec 2.0` • `Scikit-Learn` • `Librosa` • `NumPy`

---

### 🔹 Cost-Aware Temporal Deep Learning for RUL Risk Classification in Heavy-Duty Vehicles

#### *Industrial Predictive Maintenance with Cost-Sensitive Deep Learning*

A predictive maintenance framework using cost-aware temporal deep learning for Remaining Useful Life (RUL) risk classification in heavy truck engines.

#### Highlights
- Sequential degradation modelling with **Bidirectional LSTM + Attention Mechanism**
- Tackled industrial risk asymmetry with **hybrid cost-regularized loss function**
- Improved generalization via **balanced probabilistic calibration**
- Reduced operational validation costs vs. non-temporal ML baselines
- **Under review at ICCMC 2026 (IEEE)**

#### Stack
`Python` • `TensorFlow` • `Keras` • `Pandas` • `NumPy` • `Scikit-Learn`
